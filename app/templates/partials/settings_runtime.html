dB

A single change that raises the Volume, an output or input level or a route level by more than this asks for confirmation first (the app, the API and Home Assistant alike).

dB

Dropping the Volume from this web UI by more than this in one action asks first, so a slip of the slider can't silence everything unnoticed (0 = never). Home Assistant and the API are not asked: automations may lower the volume.

ms

How long the writer collects changes before sending them. Longer means fewer writes while dragging, shorter means snappier.
