What the script may contain

Literal commands, one per line, as minidsp -f runs them: output 0 gain 12, input 0 routing 1 enable on, output 0 crossover 0 0 set -- b0 b1 b2 a1 a2, output 1 peq 3 bypass off, output 0 compressor -t -30 and so on. The minidsp prefix is optional and # starts a comment. Shell loops and variables can't be read: write them out (the sample shows a whole preset expanded). Master and FIR lines are ignored with a warning.

3. What the device holds

Remembering the defaults tells the app, without checking, that the settings it can't read back (bypass flags, routing, compressor ratio and timing) are flat; on an inactive preset, which can't be read at all, it claims that for every setting. That is rarely true for a device that was set up before: import the command script you used instead. If it's wrong, later edits (un-bypassing a filter, for example) act on whatever the device really holds.
